# 🧠 Go DSA Practice

A curated collection of Data Structures and Algorithms problems solved in **Go (Golang)**. Each problem includes clear, idiomatic Go solutions with tests and benchmarks.

---

## 📂 Repository Structure

go-dsa-practice/ ├── problems/ # Problem categories │ ├── arrays/ │ ├── strings/ │ ├── trees/ │ └── ... ├── utils/ # Shared utilities ├── benchmarks/ # Optional central benchmarks ├── go.mod └── README.md

### 🛠 Requirements
- [Go 1.20+](https://golang.org/dl/)

```bash

### 📏 Run Benchmarks
